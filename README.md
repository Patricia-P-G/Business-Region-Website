# 🌍 Business Region DE-DK Website - MMD 2nd Semester Project

**A responsive business networking website built with Vue 3, JavaScript and Tailwind CSS.**

Business Region DE-DK is a web development project focused on creating an accessible and user-friendly platform that supports cross-border business connections between Denmark and Germany.

**[Live Website](https://business-region-de-dk.web.app/)**


## 📖 About the Project

This project was created during the second semester of the Multimedia Design programme at SEA – Syddansk Erhvervsakademi, Denmark. Our goal was to redesign the Business Region DE-DK website, making it more user-friendly, responsive, accessible and easier to find through search engines.

The website helps users explore business networks, learn about partner organizations, discover media content and find information about becoming a member. We worked on the project as a team of four, each contributing to different areas, including UX research, visual design, branding, content creation and frontend development.

## ✨ Key Features

- **Responsive Design** — Optimized layouts for desktop, tablet and mobile devices.
- **Search & Sorting** — Dynamic searching and alphabetical sorting of business network entries.
- **Media Filtering** — Category-based filtering of media content.
- **Membership Application** — Interactive membership form with multiple steps.
- **Reusable Components** — Modular Vue components to improve maintainability.
- **Accessibility** — Semantic HTML, ARIA attributes and keyboard-friendly navigation.
- **SEO Optimization** — Page-specific metadata, structured data, sitemap and robots.txt.

## ♿ Accessibility, SEO & Testing

Accessibility, search engine optimization and performance were considered throughout the development process to ensure a user-friendly and well-structured website.

### Accessibility
- Used semantic HTML to create a clear and meaningful page structure.
- Implemented ARIA attributes to improve accessibility.
- Ensured interactive elements support keyboard navigation.
- Developed responsive layouts for different screen sizes.

### SEO
- Added page-specific titles and meta descriptions.
- Implemented Schema.org structured data.
- Configured sitemap.xml and robots.txt.
- Followed semantic heading structures.

### Testing & Optimization
- Used **Google Lighthouse** to evaluate performance, accessibility, SEO and best practices.
- Tested the website across different screen sizes to ensure responsive behavior.
- Identified and addressed issues during development to improve usability and overall website quality.

## 🚀 Getting Started

To run the project locally, make sure Node.js and npm are installed.

**1. Clone the repository**

```bash
git clone https://github.com/Patricia-P-G/Business-Region-Website.git
cd Business-Region-Website
```

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

Create a `.env` file in the project root if you want to use the EmailJS integration.

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

**4. Start the development server**

```bash
npm run dev
```
